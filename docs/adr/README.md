# What is an ADR?
ADRs are permanent, dated records of architecture decisions that include alternatives considered, the context and reasoning that forced the choice, references related ADRs that it supersedes or was superseded by, and the status that indicates whether or not it was accepted by the team.

An ADR is not a proposal, ticket, or design doc. It is a record that explains to the reader why the code is shaped the way it is.

The unit of an ADR is one decision.
